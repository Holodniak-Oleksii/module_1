**BUG-1** — Дозволено навчання з `kohNeurons < 6` при 6 вихідних класах кольорів.

## Bug report

### BUG-1: Недостатня кількість нейронів Кохонена приймається валідатором

| Поле | Значення |
|------|----------|
| Ідентифікатор | BUG-1 |
| Заголовок | Дозволено навчання з меншою кількістю нейронів, ніж класів кольорів |
| Середовище | Windows 10, Chrome 122+, `index.html` (локально) |
| Кроки відтворення | 1) Відкрити застосунок 2) Встановити «Нейронів Кохонена» = 2 3) Натиснути «Запустити навчання» |
| Фактичний результат | Навчання стартує, мережа має лише 2 нейрони при 6 класах |
| Очікуваний результат | Помилка валідації: потрібно щонайменше 6 нейронів |
| Причина | `_validateForm` у `js/ui.js` перевіряв лише діапазон 2–20 |
| Пріоритет | Високий |
| Статус | Виправлено у v1.0.1 (`js/validation.js`) |
