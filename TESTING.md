Виявлений дефект (BUG-1): у `index.html` кнопка «Завантажити модель» викликає `triggerModelOpen()`, якого не існувало в `app.js` (функція відсутня).

## Bug report (до виправлення)

- Ідентифікатор: BUG-1
- Заголовок: Кнопка «Завантажити модель» не відкриває файловий діалог
- Середовище: Windows 10/11, Chrome 122+, локальний запуск `index.html`
- Кроки відтворення:
  1) Відкрити `index.html`
  2) Натиснути «Завантажити модель» у блоці «Навчання»
- Фактичний результат: Жодної реакції, діалог вибору файлу не з’являється
- Очікуваний результат: З’являється діалог вибору `.json`, після вибору файл завантажується в модель
- Причина: Відсутня функція `triggerModelOpen` у `app.js`
- Пріоритет/критичність: Високий (блокує імпорт моделі)
- Статус: Виправлено у v1.0.1
