# Мережа зустрічного поширення (МЗП)

**Версія:** 1.0.1

## Опис

Інтерактивний веб-застосунок для демонстрації та навчання мережі зустрічного поширення (Counterpropagation Network). Мережа складається з шару Кохонена (конкурентне навчання) та шару Гроссберга (навчання з учителем). Застосунок навчає мережу розпізнавати шість базових кольорів за RGB-вектором, показує графік MSE, історію тестів та дозволяє експортувати звіт і стан сесії.

## Стек технологій

- HTML5
- CSS3 (CSS Custom Properties, CSS Grid)
- JavaScript ES6+ (модульна структура через IIFE та класи)
- [Chart.js](https://www.chartjs.org/) (CDN) — візуалізація

## Як запустити

1. Склонуйте або завантажте репозиторій (гілка `task2`).
2. Відкрийте `index.html` у сучасному браузері (Chrome, Firefox, Edge).
3. За потреби використайте локальний сервер (наприклад, Live Server) для коректної роботи `fetch(config.json)` та `localStorage`.

## Використання

1. На вкладці **Навчання** налаштуйте параметри мережі та натисніть **Запустити навчання**.
2. Після завершення перейдіть на вкладку **Тестування**, оберіть колір (палітра або R/G/B) і натисніть **Розпізнати колір**.
3. На вкладці **Звіт та експорт** перегляньте ваги, графік порівняння експериментів і завантажте JSON-звіт, лог або файл стану.
