# МЗП (Counterpropagation Network) — Лабораторна робота (Модульний контроль №1)

Простий навчальний застосунок для моделювання мережі зустрічного поширення (МЗП), що складається з шарів Кохонена та Гроссберга. Реалізовано графічний інтерфейс у браузері та базові інструменти дослідження впливу параметрів на якість роботи мережі.

## Реалізований функціонал

- Графічний інтерфейс, орієнтований на недосвідченого користувача:
  - введення параметрів (learning rate, epochs, кількість нейронів Кохонена);
  - кнопки «Ініціалізувати», «Навчити», «Розпізнати».
- Підказки/валідація введення:
  - перевірка числових полів і діапазонів, дружні повідомлення про помилки.
- Логування подій та помилок:
  - лог-стрічка на сторінці;
  - кнопка «Завантажити log» (експорт `logs.txt`).
- Зовнішній файл конфігурації:
  - `config.json` (learningRate, epochs, kohonenNeurons), значення підтягуються у форму.
- Збереження/відновлення моделі:
  - «Зберегти модель» — експорт ваг у `cpn_model.json`;
  - «Завантажити модель» — імпорт ваг із JSON у поточну мережу.
- Побудова графіків та візуалізацій:
  - графік зміни помилки за епохами (Chart.js);
  - 2D-візуалізація розташування нейронів Кохонена й навчальних точок.
- Формування короткого звіту:
  - «Експортувати звіт» — текстовий `report.txt` з параметрами запуску та останньою помилкою.

## Як запустити

1. Відкрийте файл `index.html`.
2. За потреби відредагуйте `config.json` (дефолтні параметри навантажуються у форму при старті).
3. У веб-інтерфейсі:
   - «Ініціалізувати мережу» — створює МЗП з параметрами з форми;
   - «Навчити мережу» — запускає тренування на вбудованому наборі (XOR-подібний toy);
   - «Розпізнати» — виконує прогноз для введеного вектора, формат: `a,b` (наприклад, `1,0`);
   - «Зберегти модель» / «Завантажити модель» — експорт/імпорт ваг;
   - «Експортувати звіт» — зберігає короткий текстовий звіт;
   - «⬇️ Завантажити log» — вивантаження усіх поточних логів у файл.

## Структура проєкту

```
.
├─ index.html          # UI і стилі
├─ app.js              # логіка взаємодії з UI, графіки, виклики мережі
├─ config.json         # зовнішні налаштування застосунку
├─ logs.txt            # (необов’язково) приклад файлу логів, формується кнопкою
├─ network/
│  ├─ kohonen.js       # шар Кохонена (SOM, WTA, оновлення ваг переможця)
│  ├─ grossberg.js     # шар Гроссберга (асоціативне навчання для переможця)
│  └─ network.js       # зв’язка SOM + Гроссберг (навчання/прогноз)
└─ utils/
   ├─ logger.js        # логування у консоль і textarea, експорт у файл
   └─ config.js        # завантаження config.json, валідація та застосування дефолтів
```

## Формалізація моделі (коротко)

- Шар Кохонена: WTA-вибір переможця за евклідовою відстанню; оновлення ваг переможця у бік вхідного вектора зі швидкістю `learningRate`.
- Шар Гроссберга: для обраного нейрона-переможця коригуються вихідні ваги до цільового вектора `y`.
- Прогноз: визначення переможця на SOM → зчитування відповідного вихідного вектора зі шару Гроссберга.

## Налаштування (config.json)

```json
{
  "learningRate": 0.3,
  "epochs": 50,
  "kohonenNeurons": 3
}
```

- `learningRate` — швидкість навчання (0 < lr ≤ 1);
- `epochs` — кількість епох тренування (ціле число > 0);
- `kohonenNeurons` — кількість нейронів Кохонена (рекомендовано ≥ кількість класів).
