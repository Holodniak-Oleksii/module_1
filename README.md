# Мережа зустрічного поширення (МЗП)

**Версія:** 1.0.0

## Опис

Інтерактивний веб-застосунок для демонстрації та навчання мережі зустрічного поширення (Counterpropagation Network). Мережа складається з шару Кохонена (конкурентне навчання) та шару Гроссберга (навчання з учителем). Застосунок дозволяє задавати навчальні дані, налаштовувати гіперпараметри, спостерігати динаміку навчання у вигляді графіків та експортувати результати.

## Стек технологій

- HTML5
- CSS3 (CSS Custom Properties, CSS Grid)
- JavaScript ES6+ (модульна структура через IIFE та класи)
- [Chart.js](https://www.chartjs.org/) (CDN) — візуалізація

## Як запустити

1. Склонуйте або завантажте репозиторій.
2. Відкрийте файл `index.html` у будь-якому сучасному браузері (Chrome, Firefox, Edge).
3. Не потрібен сервер — застосунок працює повністю на стороні клієнта.

> **Рекомендація:** для коректної роботи localStorage при запуску через файловий протокол (`file://`) у деяких браузерах може знадобитися запуск через локальний сервер (наприклад, `Live Server` у VS Code).

## Використання

1. Введіть навчальні дані у форматі JSON-масивів у відповідні поля.
2. Налаштуйте параметри мережі (кількість нейронів, швидкість навчання, кількість епох).
3. Натисніть **Ініціалізувати мережу**, потім **Навчити**.
4. Для перевірки введіть вхідний вектор і натисніть **Передбачити**.
5. Результати та лог можна експортувати у форматах JSON та `.log`.
